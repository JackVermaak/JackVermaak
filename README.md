# Hi, I'm Jack

I study Infotronic Systems Engineering at Hochschule Rhein-Waal in Germany. I build small embedded devices and the software that goes with them, mostly on the Raspberry Pi Pico 2.

**Projects**

- [Pico MixPad](https://github.com/JackVermaak/pico-mixpad): a USB controller that sets Windows volume per app (CircuitPython, Python)
- [Pico Latency Tester](https://github.com/JackVermaak/pico-latency-tester): measures click-to-screen latency (C++, TinyUSB)
- [O-Grader](https://github.com/JackVermaak/ograder): every climb Adam Ondra has logged, graded on the O-grade scale (JavaScript, Cloudflare Workers)
- [Forest fire simulation](https://github.com/JackVermaak/ForestFireSpreadSim): a wildfire spread model with a Monte Carlo forecast (Python)
- [Morning Lock](https://github.com/JackVermaak/morning-lock): an Android app that locks your phone each morning until your tasks are done (Kotlin)
- [jackvermaak.com](https://github.com/JackVermaak/jackvermaak.com): my personal site
